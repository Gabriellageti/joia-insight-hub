# Joia Insight Hub

Hub de insights em triagem, possivelmente voltado a visualizacao, acompanhamento e organizacao de informacoes.

## Status

Possivel projeto principal da familia Joia. Comparar com `joia-flow` antes de decidir destaque ou arquivamento.

## Tecnologias

- Vite
- TypeScript
- React
- shadcn/ui
- Tailwind CSS

## Como rodar localmente

```sh
git clone https://github.com/Gabriellageti/joia-insight-hub.git
cd joia-insight-hub
npm install
npm run dev
```
